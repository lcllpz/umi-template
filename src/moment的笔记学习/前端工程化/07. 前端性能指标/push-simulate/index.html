定时器模拟推送 → SW → 系统通知

请用 http://localhost 打开本目录（例如用任意静态服务器指向 07. 前端性能指标），不能用 file://，否则无法注册 Service Worker。

打开后允许通知权限；主线程定时 postMessage({ type: 'SIMULATE_PUSH', body, url })，SW 里 showNotification。若页面状态在动但没有系统通知：Chrome → F12 →「应用」→ Service Workers → 本页 SW 的「inspect」打开Worker 控制台，看是否有 showNotification 报错；并检查 Windows 专注助手/系统设置里是否允许 Chrome 发通知。
