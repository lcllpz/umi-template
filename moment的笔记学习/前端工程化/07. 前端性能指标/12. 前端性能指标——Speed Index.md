## 什么是 Speed Index？

Speed Index **是一个反映页面视觉加载速度的性能指标，表示页面内容在屏幕上可见的速度，单位是毫秒（ms），数值越低越好**。

具体来说，它衡量的是：

> 用户视角下，从页面开始加载到“视觉内容大部分呈现”这一过程的平均时间。

即便页面还未完全加载完，但如果关键视觉内容（如文字、图片）已经出现在屏幕上，用户就会感觉加载很快，Speed Index 就会较低。

假设有两个页面：

- 页面 A：前 1 秒加载白屏，之后 1 秒内快速显示所有内容；

- 页面 B：从第 0.1 秒起逐步显示内容，1.5 秒时加载完成。

虽然 A 更快加载完，但由于前面一直白屏，用户“感知”的加载慢，所以 Speed Index 会比 B 高。

## Speed Index 衡量什么

Speed Index（速度指数） 是衡量网页在加载过程中内容可视化呈现速度的关键指标，反映用户多快能“看到”主要内容。Lighthouse 在评估过程中会录制页面加载的视频，分析帧与帧之间的视觉变化，并使用 [Speedline](https://github.com/pmdartus/speedline)（一个基于 Node.js 的工具）对这些数据进行处理，生成加载曲线并计算 Speed Index 分值。

数值越低，表示页面在用户视角下加载越快，体验越流畅。

Speedline 可直接分析 Chrome 性能追踪文件（trace），提取关键帧的视觉进度，用于计算包括 Speed Index、首次视觉变更时间、最终视觉稳定时间和每一帧的视觉完成度等核心指标，与 Lighthouse 的结果保持一致，非常适合用来评估网页视觉加载性能。

Speedline 不能直接分析视频文件，而是需要一个 Chrome DevTools 的 trace JSON 文件。你可以这样获得它：

1. 打开 Chrome → DevTools → Performance 面板

2. 录制页面加载 → 停止 → 点击右上角「⬇️ 导出」按钮

3. 保存 .json 文件（trace 文件）

## Lighthouse 如何计算速度指数（Speed Index）得分？

Lighthouse 会将页面的速度指数（以秒为单位）与真实网页的大量性能数据进行对比，基于分布区间给出评分。

移动端得分标准：

| Speed Index（秒） | 表现等级 | 颜色标识 |
| ----------------- | -------- | -------- |
| 0 - 3.4           | 快速     | 🟢 绿色  |
| 3.4 - 5.8         | 中等     | 🟠 橙色  |
| > 5.8             | 缓慢     | 🔴 红色  |

桌面端得分标准：

| Speed Index（秒） | 表现等级 | 颜色标识 |
| ----------------- | -------- | -------- |
| 0 - 1.3           | 快速     | 🟢 绿色  |
| 1.3 - 2.3         | 中等     | 🟠 橙色  |
| > 2.3             | 缓慢     | 🔴 红色  |

Speed Index 数值越低，表示页面内容在视觉上越快地呈现给用户，体验越好。

## 如何提升 Speed Index（速度指数）得分？

提升页面加载性能，尤其是首屏内容的可视化速度，有助于显著优化 Speed Index。以下优化策略尤为关键：

- 减少主线程阻塞：优化任务拆分，避免长时间占用主线程，提升首帧渲染速度。

- 缩短 JavaScript 执行时间：按需加载、延迟非关键 JS，减轻执行负担。

- 确保文字在字体加载前可见：使用 `font-display: swap` 等策略，避免文字“闪白”或延迟渲染。

这些优化不仅能改善 Speed Index，也能带来更快的“感知加载体验”。

## 总结

Speed Index 是衡量网页在加载过程中可视内容呈现速度的指标，反映用户多快能“看到”主要内容。它通过分析网页加载期间的视觉变化（由 Lighthouse 利用 [Speedline](https://github.com/pmdartus/speedline) 工具处理 Chrome Trace 数据生成）来计算得分。

得分越低，表示页面内容越快出现在屏幕上，用户体验越好。常见优化方法包括减少主线程阻塞、压缩 JavaScript 执行时间、以及提升首屏内容渲染效率。
